Lesson 1 · Python for a JS developer

The Core Remap

You already know how to program. This lesson rewires five JS habits into Python — then you run real Python on your machine.

The mental model

Python is closer to JavaScript than it looks: dynamically typed, first-class functions, objects everywhere. The differences are mostly surface — but surface is exactly what slows you down when reading code. Python's design creed is "there should be one obvious way to do it", so once a pattern clicks, it stays clicked.

Five remaps

1 · Blocks are indentation, not braces

A colon opens a block; the indented lines (4 spaces, by convention) are the block. Whitespace is syntax.

JavaScript

function greet(name) {
  if (name) {
    return `Hello, ${name}!`;
  }
  return "Hello, stranger!";
}

Python

def greet(name):
    if name:
        return f"Hello, {name}!"
    return "Hello, stranger!"

Notice three more remaps hiding in there: def instead of function, no const/let/semicolons anywhere, and f"..." instead of backticks — an f-string, with plain {name} (no $).

2 · Naming is snake_case

getUserName becomes get_user_name. This is a strong convention (PEP 8), and Python code that breaks it reads as foreign.

3 · One absent value: None

There is no undefined. Python has exactly one "nothing": None. Test for it with x is None, not ==. Booleans are capitalized too: True, False.

4 · == is your ===

Python's == never coerces types — 1 == "1" is False. Your JS reflex to reach for a "strict" operator can relax; the default is already strict.

Gotcha

Python also has an is operator, and it looks tempting. It checks identity (same object in memory), not value equality. Use it for None only. [1,2] == [1,2] is True; [1,2] is [1,2] is False.

Hands on: run Python the modern way

The modern Python toolchain is uv — think of it as pnpm for Python: one fast tool for projects, dependencies, and Python versions. In your terminal:

# 1. Install uv (macOS)
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. Create a project (like npm init)
uv init hello-python
cd hello-python

# 3. Run the generated file (like node main.js)
uv run main.py

Now the real exercise. Without looking back at the code above, open main.py and translate this JS into Python from memory:

function describeUser(name, isAdmin) {
  if (isAdmin && name) {
    return `${name} is an admin`;
  }
  return `${name ?? "someone"} is a regular user`;
}
console.log(describeUser("Ben", true));

Then uv run main.py. If it prints Ben is an admin, you win. (Hint for the ?? line: Python's or returns the first truthy operand, exactly like JS's || — name or "someone".) Stuck on an error? That's feedback — read the traceback bottom-up and adjust.
